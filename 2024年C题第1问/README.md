# 2024年中国研究生数学建模竞赛 C题第一问

本文件夹解决第一问“励磁波形分类”：根据一个周期内1024个磁通密度采样点，
将励磁波形识别为正弦波、三角波或梯形波。

## 文件说明

### 输入数据

- `附件一（训练集）.xlsx`：4种材料，共12,400个有标签样本；
- `附件二（测试集）.xlsx`：80个待分类样本；
- `附件四（Excel表）_空白模板.xlsx`：官方答案空白模板。

### 代码

- `main.py`：完整训练、验证、预测和结果输出程序；
- `requirements.txt`：Python依赖。

### 结果数据

- `附件二波形分类结果.csv`；
- `附件二波形分类结果.xlsx`；
- `附件四（Excel表）.xlsx`：第2列已经填入分类结果；
- `验证指标.json`；
- `五折交叉验证分类报告.txt`。

### 结果图

- `三类归一化波形.png`；
- `五折交叉验证混淆矩阵.png`；
- `特征重要性.png`。

## 方法

1. 按列位置读取1024个磁通密度采样点，规避不同材料工作表首列表头不一致；
2. 对每条波形去直流并按峰峰值归一化；
3. 提取28个分布、斜率、曲率、平台和谐波特征；
4. 使用随机森林完成三分类；
5. 使用分层五折和留一材料验证模型；
6. 使用逻辑回归进行独立一致性核验；
7. 按序号将附件二结果写入附件四第2列。

标签编码：

| 数字 | 波形 |
|---:|---|
| 1 | 正弦波 |
| 2 | 三角波 |
| 3 | 梯形波 |

## 运行

```bash
python -m pip install -r requirements.txt
python main.py
```

程序默认直接读取当前文件夹中的三个输入文件，并在当前文件夹覆盖更新结果数据
和结果图。
