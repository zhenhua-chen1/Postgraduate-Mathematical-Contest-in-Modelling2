# 2024 年“华为杯”中国研究生数学建模竞赛 C 题——第二问

题目名称：**数据驱动下磁性元件的磁芯损耗建模**


## 第二问做什么

传统 Steinmetz 方程写作

```text
P = k f^α B_m^β
```

其中 `P` 为磁芯损耗，`f` 为频率，`B_m` 为磁通密度峰值。第二问要求在材料和励磁波形均固定时，分析温度造成的差异，引入温度变量建立修正方程，并验证修正后是否比传统方程更准确。

## 本项目如何解决

1. 使用材料 1 的 1067 条正弦波样本，温度为 25、50、70、90°C。
2. 以磁通密度序列半峰峰值 `(max(B)-min(B))/2` 作为 `B_m`，减小微小直流偏置的影响。
3. 在对数空间用最小二乘拟合传统模型。
4. 令 `τ=(T-25)/65`，建立温度修正模型：

```text
P = P0 · (f/f0)^[α0+αT·τ] · (B_m/B0)^[β0+βT·τ] · exp(c1·τ+c2·τ²)
```

该式同时允许温度改变损耗尺度、频率指数和磁通密度指数，且预测值始终为正。

5. 使用固定随机种子的五折交叉验证作为主要比较依据，同时给出“留一温度验证”，检查模型对未参与拟合温度的泛化能力。

## 文件说明

| 文件 | 内容 |
|---|---|
| `材料1正弦波.xlsx` | 输入数据，从附件一筛选出的材料 1 正弦波样本 |
| `main.py` | 数据读取、模型拟合、交叉验证、结果导出与绘图 |
| `模型比较.csv` | 两个模型的五折验证和全样本拟合指标 |
| `逐样本预测.csv` | 每条样本的预测值与相对误差 |
| `温度误差统计.csv` | 各温度下的交叉验证误差 |
| `留一温度验证.csv` | 依次留出一个完整温度水平的验证结果 |
| `模型参数.csv`、`模型参数.json` | 最终方程参数与参考尺度 |
| `模型对比结果.xlsx` | 汇总版结果工作簿 |
| `实际值与预测值对比.png` | 两个模型的实际值—预测值对比 |
| `温度误差对比.png` | 各温度 MAPE 对比 |
| `残差诊断.png` | 两个模型的对数残差 |
| `温度修正参数.png` | 修正因子及指数随温度的变化 |

## 运行

```bash
python -m pip install -r requirements.txt
python main.py
```

也可指定输入文件和输出位置：

```bash
python main.py --input 材料1正弦波.xlsx --output-dir .
```

## 说明

- 主要结论应以五折交叉验证指标为准，而不是全样本拟合指标。
- “留一温度验证”比随机五折更严格，尤其是留出 25°C 或 90°C 时属于边界外推。
- 本项目未修改原始数据，所有结果均可由 `main.py` 重新生成。
