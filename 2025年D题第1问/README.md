# 2025 年“华为杯”中国研究生数学建模竞赛 D 题——第一问

题目名称：**低空湍流监测及最优航路规划**。

本项目从官方第一题原始数据开始，完整实现两个模型：模型 A 融合风廓线雷达和微波辐射计计算梯度理查逊数，模型 B 仅使用风廓线雷达的垂直空间结构和跨时次变化逼近模型 A，并输出两站、六个时次的湍流诊断垂直廓线、风险高度带和分组交叉验证结果。

## 数据

`data/raw/` 保留复现第一问所需的官方数据子集：

- a、b 两站各 6 个风廓线雷达 `ROBS` 文件；
- a、b 两站各 1 个微波辐射计文件。

程序从 12 个风廓线文件中读取到 453 个有效高度层。参赛期间的手工整理表只有 444 条，因为 a 站后 3 个时次中高于 4420 m 的 9 条有效记录被裁掉；本项目保留官方文件中的全部有效数据。

b 站微波辐射计文件含重复时次，且最早记录为 00:02，而风廓线从 00:00 开始。程序先对重复时次求均值，再进行时间插值；边界时次使用最近有效廓线，并在结果中记录最大时间差 2 分钟。

## 模型 A：双设备理查逊数模型

模型 A 的处理流程如下：

1. 解析风廓线雷达高度、风向、水平风速和垂直风速；
2. 从微波辐射计的类型 11 记录提取温度廓线和地面气压；
3. 将温度在时间和高度上插值到风廓线观测点；
4. 按静力平衡积分得到各高度气压，并计算位温；
5. 在非等距垂直网格上计算位温梯度与水平风切变；
6. 计算梯度理查逊数：

$$
Ri = \frac{(g/\theta)\,(\partial \theta/\partial z)}
{(\partial u/\partial z)^2+(\partial v/\partial z)^2}.
$$

较小的 `Ri` 表示风切变相对于稳定层结更强。代码同时给出便于可视化的 `turbulence_index = 1/(1+Ri)`；论文判断仍以原始 `Ri` 为准。

## 模型 B：仅风廓线雷达的时空模型

模型 B 不使用温度、湿度或气压。气象风向先转换为水平分量 $u,v$，对每条垂直廓线进行居中五层滑动平均，再计算风切变强度：

$$
S=\sqrt{(\partial u/\partial z)^2+(\partial v/\partial z)^2}.
$$

空间基线模型使用高度 `height_m`、垂直风速 `vertical_speed_mps` 和风切变 `model_b_shear_per_s`。

在此基础上，时空模型沿同一站点、同一高度的时间序列增加三项显式时间特征：

- 水平风矢量变化率 $\sqrt{(\partial u/\partial t)^2+(\partial v/\partial t)^2}$；
- 垂直风速变化率 $|\partial w/\partial t|$；
- 垂直风切变变化率 $|\partial S/\partial t|$。

时间梯度基于实际秒数计算，并先进行居中三时次滑动平均。只有一个时次支持的个别高空层将时间变化率设为 0，同时在结果中记录 `temporal_support_count`。为抑制极稳定层中极大的 `Ri` 对回归的支配，训练目标和输出限制在 `[0, 20]`。

全部样本拟合得到的原始线性表达式为：

```text
Ri_B = 14.5214
       + 0.00139452 × height_m
       - 2.14637 × vertical_speed_mps
       - 1296.61351 × model_b_shear_per_s
       - 1827.92499 × horizontal_wind_tendency_mps2
       - 61.47712 × vertical_wind_tendency_mps2
       + 570405.79493 × shear_tendency_per_s2
```

模型最终输出会再裁剪到 `[0, 20]`，因此上式主要用于解释各变量影响方向。

## 验证结果

相邻高度层高度相关，逐行随机划分会把同一条垂直廓线同时放入训练集和测试集。项目采用按“站点＋时次”分组的 6 折交叉验证，每次完整留出两条垂直廓线。

| 模型 | MAE | RMSE | R² |
|---|---:|---:|---:|
| 原始风变量基线 | 4.7131 | 5.7146 | 0.4748 |
| 空间风切变模型 | 3.9404 | 4.9067 | 0.6128 |
| 时空融合模型 | **3.8682** | **4.8863** | **0.6160** |

相对原始基线，时空模型的折外 `R²` 提高 0.1412，MAE 降低约 17.9%。相对纯空间模型，时间特征带来的增益较小但方向一致：`R²` 提高 0.0032，MAE 再降低约 1.8%。这一验证比参赛期间逐行随机划分得到的指标更严格。

模型 A 得到的 `Ri < 1` 风险高度带与当年论文记录一致：

| 站点 | 时次 | 风险高度带 |
|---|---|---|
| a | 00:00 | 400 m |
| a | 00:30 | 100–220 m |
| b | 00:00 | 100–340 m |
| b | 00:06 | 100–340 m |

## 运行

```bash
python -m pip install -r requirements.txt
python main.py
```

使用其他原始数据目录或输出目录：

```bash
python main.py --raw-data /path/to/question-1-data --output results --folds 6
```

运行自动测试：

```bash
python -m unittest discover -s tests -v
```

## 适用边界

- 模型 B 学习的是模型 A 的理查逊数诊断结果，不是独立飞机颠簸观测真值；
- 数据仅覆盖两个站点和 30 分钟，不能直接外推到其他季节、地形和天气过程；
- 当前时间梯度采用居中的相邻时次，适用于事后诊断与监测分析；实时因果应用应改为只使用当前及历史时次的后向差分；
- 风切变对高度分辨率和噪声敏感，部署时应结合设备质量控制和更长时间的独立验证；
- `turbulence_index` 是为直观显示增加的单调变换，不是竞赛题指定的独立物理量。
