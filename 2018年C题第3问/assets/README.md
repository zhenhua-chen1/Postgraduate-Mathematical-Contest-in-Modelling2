# 地图底图

`ne_110m_land.geojson` 为 Natural Earth 1:110m 陆地轮廓，来自维护者的 [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)。Natural Earth 地图数据为[公共领域](https://www.naturalearthdata.com/about/terms-of-use/)。

仅作方位参照，不作为恐袭数据、国家边界判断或预测输入。文件随项目保存，运行时无需联网。
