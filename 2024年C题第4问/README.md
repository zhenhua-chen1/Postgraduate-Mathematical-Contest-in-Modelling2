# 2024 年“华为杯”中国研究生数学建模竞赛 C 题——第四问

题目名称：**数据驱动下磁性元件的磁芯损耗建模**

本项目用附件一的 12400 条实验数据建立数据驱动磁芯损耗模型，对附件三的 400 个样本进行预测，并将保留一位小数的结果填入附件四第三列。文件夹完全平铺，可直接作为大型 GitHub 仓库中的一个小项目。

## 方法

模型没有直接将 1024 个磁通密度采样点全部喂给算法，而是先提取三类可解释特征：

- 工况特征：温度、频率、磁芯材料和励磁波形；
- 物理与统计特征：磁通密度峰值、RMS、峰峰值、斜率、总变差、偏度和峰度等；
- 频域特征：2–10 次谐波比、THD 和频谱质心。

预测目标为 `ln(磁芯损耗)`，可缓解损耗跨越多个数量级带来的异方差。使用温度×材料×波形分层的五折交叉验证，比较 Ridge、HistGradientBoosting、RandomForest、ExtraTrees 和 XGBoost。最终在折外预测上搜索权重，选用：

```text
ln(P_hat) = 0.5 * ln(P_HistGradientBoosting)
          + 0.5 * ln(P_XGBoost)
```

附件三只用于最终预测，没有用于模型选择或调参。

## 验证结果

| 指标 | 五折交叉验证结果 |
|---|---:|
| R² | 0.9963 |
| RMSE | 22979.47 W/m³ |
| MAE | 6678.53 W/m³ |
| MAPE | 3.59% |
| RMSLE | 0.0500 |

分组 MAPE 在各温度档位下为 3.39%–3.75%，各材料下为 2.93%–4.41%，各波形下为 3.33%–3.92%。400 个附件三样本的温度、频率、磁通密度峰值、THD 等关键特征全部落在训练集取值范围内。

## 工业应用边界

本模型适用于附件一覆盖的 4 种材料、3 种波形、4 个温度档位及相近频率和磁通密度范围。用于工程选型时，建议先做特征范围检查，并根据对应材料和波形的分组验证误差预留安全余量。对未见材料或大幅外推工况，应增加实测样本后重新训练，不应直接替代实验标定。

## 运行

```bash
python -m pip install -r requirements.txt
python main.py
```

如需从官方附件重新生成特征：

```bash
python prepare_data.py \
  --train-input "/path/to/附件一（训练集）.xlsx" \
  --test-input "附件三（测试集）.xlsx"
python main.py
```

## 可复现说明

- 不删除离群点，不用附件三的任何未知标签调参。
- 分层交叉验证、树模型和集成搜索均使用固定随机种子 `2024`。
- 由于官方附件一体积较大，仓库中保留由它无损提取的紧凑特征表和完整提取脚本。
- `附件四（Excel表）.xlsx` 中的第三列已统一保留一位小数；第二列沿用第一问生成的波形分类结果。
