# 2024 年“华为杯”中国研究生数学建模竞赛 C 题——第三问

题目名称：**数据驱动下磁性元件的磁芯损耗建模**

本项目分析温度、励磁波形和磁芯材料对磁芯损耗的独立影响、两两交互影响及影响程度，并在可比工况下给出可能使损耗最小的因素组合。目录保持完全平铺，便于作为大型 GitHub 仓库中的独立小项目。

## 为什么不能只比较原始均值

磁芯损耗同时强烈受频率和磁通密度峰值影响。如果不同温度、波形或材料组中的频率和磁通密度分布不同，直接比较算术平均损耗会把工况差异误当成因素影响。

因此，正式结论基于对数损耗协方差模型：

```text
ln(P) = 对数频率 + 对数磁通密度峰值
        + 温度 + 励磁波形 + 磁芯材料
        + 温度×励磁波形
        + 温度×磁芯材料
        + 励磁波形×磁芯材料
```

模型使用和为零对比编码和 HC3 异方差稳健检验，用偏 η² 量化效应量。此外，使用随机森林分层留出集上的分组置换重要性验证影响排名。

## 主要结论

- 在控制频率和磁通密度后，温度、励磁波形和磁芯材料的主效应均显著。
- 协方差模型的主效应量排名为：温度 > 励磁波形 > 磁芯材料。
- 三组两两交互作用均达到 0.05 显著性水平，其中“励磁波形×磁芯材料”效应最强，“温度×磁芯材料”最弱。
- 在附件一的范围内，把频率和磁通密度固定为全样本几何平均工况后，模型给出的最低损耗组合为 **90°C、正弦波、材料1**。
- 未控制工况的原始均值会给出不同材料结论，因此仅作描述，不作为正式因果结论。

## 文件说明

| 文件 | 内容 |
|---|---|
| `附件一_第三问分析数据.csv` | 从官方附件一提取的紧凑输入数据 |
| `prepare_data.py` | 从官方 4 张材料表重新提取分析数据 |
| `main.py` | 模型拟合、交叉验证、效应量、重要性及绘图 |
| `数据概况.csv` | 样本数、参考工况等 |
| `模型验证.csv` | 三层递进模型的五折验证结果 |
| `方差分析与效应量.csv` | HC3 稳健检验、偏 η² 和 Cohen's f |
| `因素与交互作用排名.csv` | 三因素及三组交互作用的效应量排名 |
| `随机森林置换重要性.csv` | 非线性模型的独立影响验证 |
| `主效应调整均值.csv` | 在参考频率和磁通密度下的因素均值 |
| `两两交互调整均值.csv` | 三组两两交互的调整损耗 |
| `48种组合调整损耗.csv` | 全部温度×波形×材料组合排名 |
| `最低损耗条件.csv` | 控制工况与未控制工况的结论对照 |
| `第三问分析结果.xlsx` | 汇总版结果工作簿 |
| `*.png` | 主效应、交互作用、效应量、组合热力图和模型验证图 |

## 运行

```bash
python -m pip install -r requirements.txt
python main.py
```

如需从官方附件一重新提取紧凑数据：

```bash
python prepare_data.py --input 附件一（训练集）.xlsx
python main.py
```

## 可复现说明

- 输入文件保留全部 12400 条样本，仅将 1024 个磁通密度点压缩为半峰峰值 `B_m=(max(B)-min(B))/2`。
- 不删除离群点，对损耗取对数处理，缓解量级跨度和异方差问题。
- 交叉验证、随机森林拆分和置换过程均使用固定随机种子 `2024`。
- “最低损耗组合”是附件一实验范围内的模型结论，不应外推至未观测材料或工况。
