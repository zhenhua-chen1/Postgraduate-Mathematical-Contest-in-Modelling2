# 2019 年 D 题第一问：车辆行驶数据预处理

本目录完成真题第一问要求：处理三份 1 Hz 车辆采样数据中的时间缺测、异常加减速度和过长低速停车，并给出每份文件的处理后记录数及可追溯明细。

## 一键运行

在 Spyder 中打开 `main.py`，点击绿色运行箭头即可。无需修改文件编号或工作目录。程序自动处理 `文件1.xlsx`、`文件2.xlsx`、`文件3.xlsx`，原始文件只读，全部新结果写入 `优化结果/`。

缺少依赖时，在 Spyder 实际使用的 Python 环境安装：

```bash
python -m pip install -r requirements.txt
python main.py
```

## 修正的旧逻辑

旧程序把 m/s 车速和 km/h 车速混合写入同一列。例如前一秒为 36 km/h、后一秒为 72 km/h 时，旧代码写成 13.96 km/h；按 3.96 m/s² 的上限应写成 50.256 km/h。新版所有速度均以 km/h 保存，仅在计算加速度时除以 3.6。

旧程序判断两秒间隔能否插值时忽略了时间差，并在部分情况下把后一时刻车速直接复制到缺失秒。新版仅对恰好两秒的间隔补一个线性中点；更长缺口保留为新的连续数据段，不虚构长时间轨迹。

旧程序用累计行数代替连续时间段，遇到长缺口也不重置低速计数。新版只在时间连续的段内识别低速过程，把连续低于 10 km/h 的长低速段最多保留 180 条 1 Hz 记录。

## 方法与约束

1. 检查必需字段、时间格式、时间严格递增且不重复、车速非负。
2. 对两秒间隔补一个线性插值点，同时插值数值型传感器；超过两秒不补点。
3. 在连续 1 Hz 记录内，限制加速度不超过 3.96 m/s²、减速度不低于 −8 m/s²。修正按时间顺序进行，保证相邻处理后车速满足限制。
4. 连续速度低于 10 km/h 的段最多保留 180 条，删去的部分记录到处理明细。
5. 输出保留 `原GPS车速`、`原始行号` 和 `处理标记`。插值行没有原始行号；原始附件始终保留不变。

真题没有提供道路坡度、隧道范围或人工标注，因此无法唯一判断每个速度突变的真实原因。这里采用题面给出的物理边界进行确定性限幅，便于复现和核查。

## 完整运行结果

| 文件 | 原始记录 | 两秒补点 | 车速修正 | 长低速删除 | 处理后记录 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 文件1 | 185,725 | 111 | 33 | 7,197 | 178,639 |
| 文件2 | 145,825 | 1,743 | 392 | 5,131 | 142,437 |
| 文件3 | 164,914 | 341 | 160 | 5,978 | 159,277 |

三份结果的连续低速段最长均为 180 条。连续 1 Hz 记录的最大加速度为 3.96 m/s²，最大减速度绝对值为 8 m/s²；超过两秒的时间缺口没有补造数据。
